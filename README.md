# hand-gesture-web#
🤖 AI Hand Gesture Recognition

A browser-based AI hand gesture recognition application built with HTML, CSS and JavaScript using MediaPipe Hands.

## Features

- ✅ Multi-Hand Detection
- ✅ Real-time Camera
- ✅ Hand Landmark Detection
- ✅ Gesture Recognition (Basic)
- ✅ Gesture History
- ✅ Dark / Light Theme
- ✅ Audio Feedback
- ✅ Screenshot Capture
- ✅ Full Screen Mode
- ✅ Mobile Friendly
- ✅ Works on GitHub Pages
- ✅ No Server Required

## Technologies

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands

## How to Run

1. Clone or download the project.
2. Open the project in VS Code.
3. Run using Live Server or deploy to GitHub Pages.
4. Allow camera permission.
5. Show your hand to the camera.

## Supported Gestures

- 🖐️ Open Palm
- ✊ Fist
- ✌️ Peace
- 👍 Thumbs Up
- ☝️ Pointing Up

More gestures can be added by extending `gestureRecognizer.js`.
